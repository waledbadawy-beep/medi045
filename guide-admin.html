2 · Releasing marks — your job alone

Supervisors mark cases; they cannot release them. Release Marks to Students lists everything waiting, with the student, the case, who marked it and the total.

Release one at a time, or all at once. Every release is written to the audit log with your name. A student sees nothing until you do this.

3 · The other sections

  • Change Password — admin password and supervisor PIN

  • Backup — send a CSV now; one is also emailed nightly at midnight Riyadh time
  • Batch Management — open and close a batch, set the deadline
  • Grading Configuration — required case counts per activity
  • Post to All Students — announcements, with an optional attachment
  • eLearning Links — add or remove videos in any of the nine sections. Students get them on their next sync; no app update needed.
  • Audit Log — who did what, including every release and deletion
  • Data Management — export, and the destructive resets

The class code is sent to students with the app link. It stops anyone outside the course reaching the data; it does not stop one student from seeing another's records, because there are no individual student accounts.

Class codes are held as secrets on the Cloudflare Worker. Changing one means editing the secret there, then telling the batch.

5 · What cannot be undone

There is no import. The CSV export is an export only — it cannot put data back. Before any reset:
  • Take a backup from the Backup section and check the email arrived
  • Cloudflare D1 keeps a 30-day history — /bookmark in the D1 console records a point you can return to
Erasing every record requires typing DELETE ALL RECORDS in full. That guard is deliberate.

6 · If the app says the server refused something

A message naming an older version means worker.js needs redeploying: Cloudflare → the Worker → Edit code → paste the current file → Save → Deployments → Promote version.

Promote is the step people miss. Saving alone changes nothing.

Nothing is lost meanwhile — records wait on the device and upload once the server is current.
